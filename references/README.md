## Learning approach

Rather than collecting frameworks or reproducing lectures, I focus on a small evidence-based cycle:

1. Read one concept from the original source.
2. Identify a practical engineering question that concept helps answer.
3. Apply it to an existing project or a minimal, bounded lab.
4. Verify through tests, measurements, or a reviewable technical explanation.
5. Record limitations, open questions, and follow-up study.
